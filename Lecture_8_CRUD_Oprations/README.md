# 🧩 CRUD Operations in Express.js

## 📘 What is CRUD?

**CRUD** stands for **Create, Read, Update, and Delete** —  
the four basic operations that can be performed on data in most web applications or databases.

It represents the fundamental actions needed to manage data in any application, whether using a database or file system.

---

## ⚙️ CRUD Operation Breakdown

| Operation | HTTP Method | Description | Example Endpoint |
|------------|--------------|--------------|------------------|
| **Create** | `POST` | Adds (creates) new data or a record | `/items` |
| **Read** | `GET` | Retrieves (reads) existing data | `/items` or `/items/:id` |
| **Update** | `PUT` / `PATCH` | Modifies (updates) existing data | `/items/:id` |
| **Delete** | `DELETE` | Removes (deletes) existing data | `/items/:id` |
