# 🧩 Backend Revision — Node.js Full Course

This repository contains a complete **Node.js backend revision series**, organized lecture by lecture.  
Each folder focuses on a specific backend concept or project — from basic Node modules to advanced authentication and full-stack integration.

## ⚙️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/ujjwalkumarsahni/Backend-Revision.git
   cd Backend-Revision

2. **Install dependencies**

   ```bash
   npm install
   ```
